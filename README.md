CornerGrocer C++ Project

Project Summary

This project was developed for my CS 210 Programming Languages course at Southern New Hampshire University. The CornerGrocer program helps a grocery store analyze how frequently customers purchase different items. It reads an input file, counts item frequencies, and displays the results through a menu, including a text-based histogram. It also creates a backup file containing item frequencies.

What I Did Particularly Well

I am proud of how I organized the program to perform different tasks using C++. I worked on creating a menu that allows users to select different options and view grocery item frequencies. I also improved my understanding of file handling, loops, and functions while developing the program.

Areas for Improvement

I could improve my code by adding stronger input validation and error handling. These improvements would prevent unexpected inputs from causing problems and make the program more secure and reliable. I could also improve efficiency by organizing repeated operations into reusable functions.

Challenges and How I Overcame Them

One of the most challenging parts was working with file input and output and ensuring the program correctly calculated item frequencies. I overcame these challenges through testing, debugging, and reviewing my code in Visual Studio. I learned to pay closer attention to syntax and program logic. I will continue using Visual Studio, debugging tools, and programming documentation to strengthen my skills.

Transferable Skills

This project helped me develop problem-solving, debugging, file handling, and C++ programming skills. I also gained experience using Visual Studio and organizing code. These skills will be useful in future programming courses, cybersecurity studies, and software development projects.

Maintainability, Readability, and Adaptability

I worked on making my program readable by organizing the code into functions and using meaningful variable names. Breaking the program into smaller sections made it easier to understand, test, and modify. This structure will also make it easier to add new features or improve the program in the future.
