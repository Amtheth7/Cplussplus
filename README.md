# CornerGrocer C++ Project

## Project Summary
This project was developed for my CS 210 Programming Languages course at Southern New Hampshire University. The CornerGrocer program helps a grocery store track how frequently items are purchased. It reads an input file, counts item frequencies, and displays the results through a menu, including a text-based histogram. It also creates a backup frequency file.

## What I Learned
This project strengthened my understanding of C++ programming, file input and output, loops, functions, and organizing code. I learned how to use programming to solve a real-world business problem.

## Challenges and Improvements
One challenge was making sure the program correctly read the input file and calculated item frequencies. Testing and debugging helped me identify and correct errors. In the future, I could improve input validation, error handling, and code documentation.

## Skills Gained
I gained experience with Visual Studio, debugging, file handling, and writing reusable C++ code. These skills will be useful in future programming courses and software development projects.
